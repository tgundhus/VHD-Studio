What VHD Studio fixes

Windows can open a virtual disk, but the jobs around it need the Hyper-V PowerShell module (missing on Windows Home), diskpart scripts or Disk Management. VHD Studio does them in one window.

01Compact a VHDX without Hyper-V

WSL 2 and Docker Desktop ext4.vhdx files only ever grow, and Optimize-VHD isn't available on Home. Compact VHD and VHDX files in full (NTFS/ReFS-aware) or zeroed-blocks-only mode for Linux images, optionally after wsl --shutdown, and see the size before and after.

02Auto-mount VHD and VHDX at startup

Windows forgets attached disks on reboot, Dev Drive VHDX files included. A small Windows service re-attaches them at boot: read-only, without a drive letter, or mounted into an empty folder. Users without admin rights can attach disks they have access to.

03Fix “Access denied” after a crash

A VHDX that wasn't closed cleanly after a crash or power loss has a pending log, and Windows refuses it with a confusing error. VHD Studio detects the log and replays it so the disk attaches normally.

04Resize, shrink and convert

Grow VHD and VHDX files, or shrink a VHDX to its smallest safe size. Convert VHD ↔ VHDX, dynamic ↔ fixed, and 512 ↔ 4K logical sectors. The source file is never modified.

05Repair differencing disk chains

Create a child disk to experiment safely, then merge it into its parent or discard it. Fix a broken parent path after a move (the Set-VHD -ParentPath equivalent) or reset a duplicate disk identifier.

06A DiskPart GUI that's hard to misuse

Initialize, partition, format, extend and shrink, assign letters and folder mounts. System and boot disks can't be changed, physical disks stay read-only until you unlock them, and every change shows the equivalent PowerShell command first.

Built not to lose your data

No action in VHD Studio loses data unless you chose a destructive action and confirmed it. An end-to-end test suite checks the data on real virtual disks byte for byte after every operation.

Read the full data-safety model

  • A verified backup before every in-place change: the checksum is re-read from disk, and Windows must be able to open the backup as a virtual disk.
  • Disks that are attached, in use, or changed since you selected them are refused, not guessed at.
  • New disks, conversions and backups never replace an existing file.
  • System, boot, page-file and image-hosting disks are protected.
  • Volumes are flushed and locked before detach. Open files mean a retry prompt, not lost work.
  • Destructive actions need typed confirmation, and every change is written to an audit log.

The successor to VHD Attach

VHD Studio is based on VHD Attach by Josip Medved, who created it and maintained versions 1.0 to 4.22 from 2009 to 2020. The attach engine and auto-mount service are his work. VHD Studio 5 moves the code to .NET 10 and adds the maintenance tools, the Disk Manager and data-safety hardening.

Upgrading is automatic: setup removes VHD Attach 4.x and its service, and keeps your auto-mount list.

Frequently asked questions

Does VHD Studio need Hyper-V?

No. VHD Studio uses VirtDisk.dll and the Storage Management API, which are part of every Windows 10 and 11 edition, including Home. The Hyper-V PowerShell module is not needed.

How do I compact a WSL or Docker ext4.vhdx file?

Run fstrim inside the Linux distribution so freed space is zeroed, then open the ext4.vhdx in VHD Studio and choose Maintenance → Compact → Zeroed blocks only. VHD Studio can run wsl --shutdown first to release the file, and shows the size before and after.

How do I auto-mount a VHD or VHDX at startup?

Open the disk in VHD Studio and turn on auto-mount from the toolbar. The VHD Studio service re-attaches it at every boot, optionally read-only, without a drive letter, or mounted into an empty folder. This also works for Dev Drive VHDX files, which Windows does not re-attach on its own.

Why does my VHDX give “Access denied” after a crash?

A VHDX that was not closed cleanly, for example after a crash or power loss, has a log that has not been replayed, and Windows refuses to attach it. VHD Studio detects the pending log and replays it so the disk attaches normally. A read-only attach never writes to the file; it points you to Repair → Replay log, which makes a backup first.

Is VHD Studio the same as VHD Attach?

VHD Studio is the successor to VHD Attach by Josip Medved, who maintained versions 1.0 to 4.22 from 2009 to 2020. VHD Studio 5 keeps his attach engine and auto-mount service and adds maintenance tools, a Disk Manager and data-safety hardening. Setup removes VHD Attach 4.x automatically and keeps your auto-mount list.

Is VHD Studio free?

Yes. VHD Studio is free and open source under the MIT license. The source code is on GitHub.
